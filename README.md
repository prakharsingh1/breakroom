# Breakroom sandbox adapter example

A scripted support-refund adapter for the Breakroom agent sandbox. Import this commit with repository prakharsingh1/breakroom. The corrected entrypoint reconciles ambiguous results; change it to agent:faulty to reproduce duplicate refunds. These are synthetic examples, not an AI model benchmark or safety certification. Replace agent.py with your own adapter. No dependencies or provider keys are needed. See the main branch docs/sandbox.md for the interface, supported runtime and limits.
